- New Feature: Runtime Status Panel — a server-rack icon in the masthead opens a slide-out panel on the build canvas showing all runtimes' status, version, type, and expandable detail (Runtime ID with copy, instance ID, cloud info, install date). Click-outside closes the panel. Polls every 60 seconds. Configurable in the Options page under Build Enhancements.
- New Feature: Process Analysis Dashboard — the extract button now performs a multi-tab analysis of your entire process: Set Properties, Notifications, Messages, SQL Queries, Decisions, Maps, Scripts, Properties, Flow, Overrides, and Shape Inventory. Uses the Boomi API when a token is configured (single XML call), falls back to DOM-based Set Properties extraction when no token is available. Grouped property references, shape-to-shape connections, and per-environment overrides included. Export per-tab or all tabs as TSV.
- New Feature: Component References — a link icon (🔗) next to the component name opens a modal showing all components that use this component ("Used By") and all components this component references ("References") with recursive tree walk, component type badges, version, DEPENDENT/INDEPENDENT labels, deleted indicators, and folder/modified-date tooltips. Requires Boomi API token.
